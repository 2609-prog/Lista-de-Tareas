Este proyecto es una aplicación de escritorio desarrollada en Python con Tkinter, que permite gestionar una lista de tareas de manera sencilla e intuitiva. 
Con esta herramienta el usuario puede añadir nuevas tareas, marcarlas como completadas (con un ✔) y eliminarlas cuando ya no sean necesarias. 
El objetivo es practicar la programación orientada a objetos en Python y el uso de interfaces gráficas con Tkinter.
